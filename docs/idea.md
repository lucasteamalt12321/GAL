## Название

**Global Achievement List (GAL)** — глобальная система оценки и ранжирования
сложности достижений.

## Тема исследовательской работы

«Разработка глобальной системы оценки сложности разнородных достижений на
основе попарных сравнений и математической модели Bradley–Terry».

## 1. Актуальность

В цифровом пространстве существует множество достижений — в играх, спорте,
программировании, интеллектуальной деятельности и других областях. Объективно
сравнить их сложность трудно: существующие рейтинги ограничены одной
дисциплиной либо опираются на субъективные числовые оценки.

Проблема: как построить универсальную систему, позволяющую сравнивать сложность
достижений из разных областей, используя опыт большого количества людей?

## 2. Основная идея

GAL — веб-платформа для сбора, проверки и глобального ранжирования
пользовательских достижений.

Основной принцип — **индивидуальные шкалы сложности**. Каждый пользователь
формирует собственную последовательность достижений: выполняя новое достижение,
он размещает его между уже пройденными и тем самым указывает, какие из них были
легче, а какие сложнее.

Из индивидуальных шкал система получает множество попарных сравнений и
объединяет их в единую глобальную шкалу сложности. Для этого предполагается
использовать математическую модель **Bradley–Terry**, которая вычисляет
относительную сложность объектов по результатам попарных сравнений.

## 3. Цель

Разработка универсальной информационной системы для оценки и ранжирования
сложности разнородных достижений на основе коллективного пользовательского
опыта и математической модели попарных сравнений.

## 4. Задачи

- исследовать существующие способы оценки и ранжирования сложности;
- разработать механизм формирования индивидуальных шкал достижений;
- разработать алгоритм преобразования пользовательских шкал в попарные сравнения;
- реализовать модель Bradley–Terry для вычисления глобальных рейтингов;
- разработать систему регистрации, добавления и верификации достижений;
- реализовать механизм модерации пользовательских материалов;
- провести экспериментальную проверку точности и устойчивости рейтингов;
- создать доступную веб-платформу для взаимодействия пользователей.

## 5. Объект и предмет исследования

- **Объект:** процессы оценки и сравнительного ранжирования сложности
  разнородных достижений.
- **Предмет:** математические методы обработки попарных сравнений и
  формирования глобальной шкалы сложности.

## 6. Научная новизна

Предлагается подход к формированию глобального рейтинга сложности, основанный
на объединении индивидуальных шкал пользователей. В отличие от прямого
выставления числовых оценок, система использует относительное положение нового
достижения среди ранее выполненных — так собираются сравнительные данные без
необходимости определять абсолютную сложность каждого достижения. Модель
Bradley–Terry преобразует эти данные в единую шкалу относительной сложности.

**Важно:** новизну самого подхода ещё предстоит обосновать сравнением с
существующими методами. Нельзя утверждать, что Bradley–Terry или попарные
сравнения впервые применяются для такой задачи.

## 7. Практическая значимость

- сравнение достижений в различных видеоиграх;
- формирование рейтингов спортивных результатов;
- сопоставление интеллектуальных и технических достижений;
- создание глобальных пользовательских рейтингов;
- анализ коллективных оценок сложности.

## 8. Ожидаемый результат

Функционирующая веб-платформа GAL, где пользователи добавляют достижения,
подтверждают их выполнение и формируют индивидуальные шкалы сложности. На
собранных данных система рассчитывает глобальные рейтинги моделью
Bradley–Terry. Дополнительно проводятся эксперименты, оценивающие достоверность,
устойчивость и применимость метода.

## Краткая презентация идеи для жюри

### GAL — Global Achievement List

**Можно ли измерить сложность любого достижения?**

GAL решает проблему сравнения достижений из совершенно разных областей. Каждый
пользователь самостоятельно выстраивает свои достижения по сложности. Система
объединяет тысячи таких индивидуальных шкал с помощью математической модели
Bradley–Terry и формирует глобальный рейтинг.

Задача — создать универсальную систему, позволяющую сравнивать достижения людей
независимо от области деятельности.
