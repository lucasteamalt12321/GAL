# Product Context — GAL

## Проблема

Достижения из разных сфер практически невозможно сравнивать:

- насколько прохождение Bloodbath сложнее сложного произведения на пианино;
- насколько высокий шахматный рейтинг сопоставим с разработкой сложного проекта;
- насколько сложный образовательный результат сопоставим с достижением в видеоигре.

Обычные рейтинги работают только внутри своей сферы.

## Решение

GAL создаёт единую относительную шкалу сложности достижений через личные сравнения.

Вместо «Насколько сложно?» система спрашивает:
> «Где это находится относительно того, что ты сам уже смог сделать?»

Множество независимых личных сравнений формируют глобальную шкалу, связывающую разные сферы («снизу вверх», через сеть пользователей).

## Ключевые продуктовые принципы

1. **Разделение трёх понятий:** Выполнение (доказано) ≠ Оценка (субъективное личное сравнение) ≠ Глобальный рейтинг (объединение оценок).
2. **Верифицируемость:** достижение публикуется только после подтверждения собственного выполнения создателем + proof.
3. **Оценка только из личного опыта:** пользователь оценивает только те достижения, которые сам выполнил (approved completion обязателен).
4. **Устойчивость к субъективности:** одно достижение = одна оценка; позиция = среднее арифметическое; после появления рейтинга оценки фиксируются.
5. **Динамичность:** каждая новая оценка может изменить позицию, очки игроков и leaderboard — всё пересчитывается автоматически.

## Целевая аудитория

Люди, имеющие реальные достижения в одной или нескольких сферах (игроки GD, музыканты, шахматисты, программисты, Minecraft-игроки, учащиеся, спортсмены) и заинтересованные в сравнении сложности между сферами.

## Северная звезда (North Star)

Количество подтверждённых достижений, для которых существует достаточно независимых оценок для формирования устойчивого глобального рейтинга.

## Основной Loop

```text
Achievement → Proof → Moderation → Evaluation → Global Rank → Player Points → Leaderboard → Discovery → ...
```
